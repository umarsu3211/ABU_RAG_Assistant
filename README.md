## Project Overview
RAG-based Administrative Knowledge Assistant for Ahmadu Bello University using Retrieval-Augmented Generation.

**Course:** COEN 872 SYSTEM DEVELOPMENT

## Features
- 3.2 Data Collection from Official ABU Documents
- 3.3 Document Preprocessing (Conversion, Cleaning, Segmentation, Metadata, Embeddings)
- 3.4 Knowledge Base with FAISS Vector Database
- 3.5 Retrieval Module (Similarity Search) + LLM Generation
- 4.1.3 Source Referencing (Document + Page Number)
- 3.7 Evaluation Metrics (Accuracy, Relevance, Response Time, Satisfaction, Precision, Recall)

## How to Run
pip install -r requirements.txt
streamlit run app.py

## Implementation Stack (3.6)
- Python
- LangChain
- FAISS (Vector DB)
- Sentence-Transformers (all-MiniLM-L6-v2)
- Streamlit
- PyPDF / Docx processing
